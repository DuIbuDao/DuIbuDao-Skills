# 官方图 → 场景渲染图 及自检

## 产出规范
- 一张生活场景主图（无文字，可放品牌 logo），一张白底备用主图，5–7 张场景详情图；放版本目录 `v1/`，附联系表（contact sheet）和每张图的思路说明。
- 产品外观、颜色、五金、配件必须与官方图一致；场景真实，避免棚拍感。
- 卖点只写拿得出证据的，每条对应详情页原文。
- 做完不上传任何平台，交审。

## 交付前自检
1. **配件误导**：官方图里出现、但标题/卖点没写附赠的小配件，渲染图里要么去掉要么标出，让老板定。
2. **文图一致**：文案写的用法（如 Crossbody 斜挎）画面必须真的是这个用法，否则重做或删词。
3. 纹理/压纹等 AI 还原的细节要说明「接近但非逐像素一致」。
4. 缺实拍角度（底部、开孔、内衬）就砍掉对应卖点，不靠 AI 编细节；同时把缺的角度加入补拍清单。

## 素材建议
按 SKU 固定补拍清单：每色正/背/底/侧开孔/内衬 + 上身场景图，外加 3–5 条 5 秒动作短片（开合、装电脑、上肩），统一放 `assets/<SKU>/` 下的 photos/ 与 footage/，图和视频共用。
