# 多岗位每日待决策看板

目标：让老板一眼看到「哪些事等我拍板、多急、文件在哪」，而不是读各个 bot 的流水账。

## 步骤
1. **定时间窗**：明确写出北京时间范围（如 前一天 22:00 – 当天 22:00）。
2. **先扫已有回报**：把窗口内各岗位已经交的产出和文件过一遍，能从已有回报得到的就不再打扰对方。
3. **按岗位定制状态请求**（缺什么才问），统一要求：
   - 5 行以内，只用已有产出，**不要为此停下手上的活**；
   - 每条写：事项、当前状态、需要老板决定的具体问题、截止或发生时间（北京时间）、文件路径；
   - 给出该岗位的重点提示（如：价格异常、待审回复、待终审视频、值得跟进的达人）；
   - 没有待办必须明确写「无待办」，不能空着；
   - 隐私：只给会话/订单编号，不要客户姓名、联系方式、地址；达人只给公开 handle 和公开数据，不给邮箱电话。
4. **核实**：逐一检查回报里的文件路径是否存在；没回状态的岗位用它最近一次产出顶上并注明来源；长期没人报进度的旧事项标「状态未知」，不要补编。
5. **写摘要文件**：按「最急 → 次急」分组，顶部突出最近的硬截止（如活动结束时间）。
6. **交给 Page 助手建页**：同一张 Page 原地更新、链接不变；默认私密，分享级别只能由所有者自己改（选「团队」，不要「公开」）。
7. **给老板的汇报**：一句结论（几个岗位有更新、几个有待拍板、最急的是什么）+ Page 链接 + 未回报岗位。

## 坑
- 一次性要状态时容易让执行中的岗位停工，务必写「别停下手上的活」。
- 「未知」照实保留，比编一个数更有用。
- 后续修正（时间、进度）直接改同一张 Page，不要另建。
